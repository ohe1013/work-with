# Codex Review Prompt

아래 문서를 먼저 읽어라.
- @AGENTS.md
- @docs/product-invariants.md
- @docs/milestones.md
- @docs/acceptance-checklist.md
- @progress/current.md

Goal
- 현재 구현이 활성 마일스톤 acceptance criteria를 충족하는지 검토한다.

Review checklist
1. 제품 골자 유지 여부
2. 지도 중심 UX 유지 여부
3. 모바일/데스크톱 대응 여부
4. placeholder 잔존 여부
5. 상태 UI 누락 여부
6. 검증 커맨드 통과 여부
7. 문서와 구현의 불일치 여부

Output format
- Pass / Needs changes
- Critical issues
- Non-critical polish
- Missing validations
- Recommended next task
