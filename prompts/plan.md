# Codex Plan Prompt

아래 문서를 먼저 읽어라.
- @AGENTS.md
- @docs/product-invariants.md
- @docs/toss-inspired-ui-spec.md
- @docs/user-flows.md
- @docs/milestones.md
- @progress/current.md

Goal
- 제품 골자를 바꾸지 않고 현재 레포 기준으로 다음 구현 계획을 세운다.

Constraints
- 운동 메이트 탐색/모집이라는 본질을 유지한다.
- 지도 중심 경험을 유지한다.
- Toss-inspired 원칙을 적용하되 직접 복제하지 않는다.
- 현재 레포 구조를 최대한 존중한다.
- 활성 마일스톤 밖의 adjacent feature를 제안하지 않는다.

Output format
1. 현재 상태 요약
2. 가장 위험한 부분 3개
3. 다음 마일스톤의 작업 항목
4. 수정 가능성이 높은 파일
5. 검증 커맨드
6. 완료 조건

Important
- 구현은 하지 말고 계획만 작성한다.
- 계획은 추상적으로 쓰지 말고 파일/화면/흐름 기준으로 작성한다.
