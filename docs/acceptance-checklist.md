# Acceptance Checklist

## 공통
- [ ] 제품 골자가 유지된다.
- [ ] 지도 중심 경험이 살아 있다.
- [ ] 모바일과 데스크톱에서 모두 사용할 수 있다.
- [ ] 빈 상태 / 로딩 / 에러 상태가 있다.
- [ ] README와 docs가 구현과 크게 어긋나지 않는다.

## 홈
- [ ] 홈 첫 진입에서 지도와 탐색 목적이 동시에 보인다.
- [ ] 마커와 리스트 선택이 연결된다.
- [ ] 필터 진입이 쉽다.
- [ ] 상세 확인 동선이 자연스럽다.

## 찾기
- [ ] `/find`가 조건 기반 탐색 화면으로 동작한다.
- [ ] 홈과 역할이 구분된다.
- [ ] 빈 결과 상태가 친절하다.

## 등록
- [ ] `/regist`가 실제 등록 화면이다.
- [ ] 필수 입력 검증이 있다.
- [ ] 제출 직전 요약이 있다.
- [ ] 성공/실패 피드백이 있다.

## 로그인
- [ ] 로그인 화면이 동작한다.
- [ ] 실패 메시지가 구체적이다.
- [ ] 로그인 후 복귀 흐름이 자연스럽다.

## 코드 품질
- [ ] `yarn --cwd client lint`
- [ ] `yarn --cwd client build`
- [ ] `yarn --cwd client test`
- [ ] `yarn --cwd server build`
