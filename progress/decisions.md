# Decisions

## D-001
제품은 운동 메이트 탐색/모집 서비스로 유지한다.
피드형 커뮤니티나 일반 SNS로 확장하지 않는다.

## D-002
지도 중심 경험은 삭제하지 않는다.
홈은 계속 map-first experience의 중심이어야 한다.

## D-003
디자인 방향은 "Toss-inspired" 원칙을 따른다.
단, 특정 제품 UI를 직접 복제하지 않는다.

## D-004
새 UI 작업은 Tailwind 우선으로 진행한다.
기존 코드에 있는 다른 스타일링 방식은 필요한 범위 안에서만 유지한다.

## D-005
구현은 milestone 단위로 자른다.
현재 마일스톤 acceptance criteria를 닫기 전에는 인접 기능을 확장하지 않는다.

## D-006
모바일 우선으로 설계하고, 데스크톱은 같은 컴포넌트 시스템을 확장해 대응한다.

## D-007
프런트는 외부 API 원문에 직접 묶이지 않고,
서버 또는 adapter layer를 통해 더 안정된 계약을 사용한다.
